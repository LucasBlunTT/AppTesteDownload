# AppTesteDownload

Servidor HTTP leve em Node.js, projetado para testes de **download**, **velocidade de rede** e **transferência de arquivos**.  
Não requer instalação do Node.js no sistema — utiliza um runtime portátil.

---

## 📦 O que acompanha o pacote

- `server.js` — Servidor HTTP simples para disponibilização de arquivos.
- `iniciar-servidor.bat` — Script para iniciar o servidor usando Node.js portátil.
- `nodejs/` — Pasta onde deve ser colocado o Node.js Autônomo (portátil).
- `teste.zip` — Arquivo de teste para validação de download.

---

## 🧩 Node.js Autônomo (Portátil)

Para rodar o servidor sem instalar nada na máquina, utilize a versão portátil do Node.js:

### 🔗 **Download do Node.js Autônomo**
Versão utilizada no projeto:  
https://nodejs.org/dist/v24.11.1/node-v24.11.1-win-x64.zip

### 📌 Após baixar:
1. Extraia o ZIP.
2. Renomeie a pasta extraída para: nodejs
